Motor MÉDICI™ v0.1 · activado

La regla ya no queda sólo como declaración. Innova_N dispone de un motor interno reproducible que calcula por servicio + periodo, genera un ledger Git off-chain y deja pendientes los casos sin evidencia en lugar de inventar cantidades.

Q = media(calidad, utilidad, continuidad, trazabilidad) MÉDICI_CANDIDATO = VALOR_VALIDADO × FRACCIÓN_NO_COMPENSADA × Q × CONFIANZA PAGO COMPLETO → FRACCIÓN_NO_COMPENSADA = 0 → MÉDICI_DIRECTO = 0

La fase actual es contabilidad off-chain trazable. No equivale a emisión blockchain, dinero, equity, participación jurídica ni voto soberano. Cuando falte un dato, el estado correcto es pendiente.
