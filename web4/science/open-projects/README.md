# ES · Castellano

## Qué es

Un índice público y ampliable de proyectos científicos abiertos que encontramos en GitHub y que merecen ser **visitados, comprendidos y, cuando los derechos lo permitan, visualizados o reproducidos** desde WEB4™.

La selección no implica que Innova_N, NEOCore™ o los autores externos estén afiliados entre sí. Tampoco es una certificación de verdad científica. Es una puerta de exploración con retorno permanente a la fuente original.

## Primera constelación

### Neurociencia, connectómica y cerebro

- **malecns · natverse** — paquete R para acceso programático a datasets recientes de Janelia FlyEM; licencia GPL ≥3 para el código del paquete.
- **Fly Brain Minecraft** — MaleCNS convertido en una red LIF que controla una mosca en Minecraft.
- **DOOMFLY** — experimentación MaleCNS en ViZDoom, incluida una línea de plasticidad con resultados negativos documentados.
- **Fly64** — demostración experimental MaleCNS + Super Mario 64; su autor advierte que no debe asumirse como software científico revisado.
- **Neuroglancer** — visor WebGL para datos volumétricos de neurociencia.
- **brainrender** — visualización de anatomía cerebral en espacio de atlas.
- **The Virtual Brain** — simulación de redes cerebrales a escala de cerebro completo.

### Astronomía y universo

- **Aladin Lite** — atlas celeste ligero ejecutado en navegador; base del prototipo de visor de cielo profundo de WEB4™.
- **Astropy** — infraestructura Python abierta para astronomía y astrofísica.
- **OpenSpace** — astrovisualización interactiva desde escalas planetarias hasta cosmológicas.

### Imagen y visualización científica

- **napari** — visor interactivo multidimensional para Python.
- **PyVista** — visualización y análisis 3D sobre VTK.

### Simulación biológica y molecular

- **OpenWorm** — iniciativa abierta orientada a modelar *C. elegans* y avanzar hacia simulación integral del organismo.
- **OpenMM** — toolkit de alto rendimiento para simulación molecular.

### IA para ciencia

- **AlphaFold** — código abierto del método de predicción estructural de proteínas; su repositorio histórico está archivado y se conserva como referencia, no como proyecto activo.

## Cómo visualiza WEB4

La página viva no necesita copiar screenshots para resultar visual. Puede representar cada proyecto mediante una **constelación propia de nodos**, categorías, relaciones, licencias, actividad y estados; cada nodo abre su ficha y el repositorio original.

Sólo se incorporará material externo dentro de WEB4 cuando exista base de derechos verificable:

```text
LINK_ONLY
→ descripción propia + metadatos + enlace canónico

LICENSE_VERIFIED
→ reutilización dentro del alcance exacto de la licencia

EXPLICIT_PERMISSION
→ permiso adicional documentado del autor/titular
```

La licencia del repositorio se registra por separado de los derechos de **datos, papers, imágenes, screenshots, logos y marcas**.

## Criterios mínimos de entrada

Un proyecto debe disponer de un origen identificable, utilidad científica o de visualización científica comprensible y suficiente información para registrar procedencia. El catálogo conserva estado del repositorio, licencia cuando está verificada y estado epistemológico. Si faltan derechos para media, el estado permanece `LINK_ONLY`.

No se ordena por estrellas. La popularidad puede ser un dato contextual, pero **POPULARIDAD ≠ VALIDEZ CIENTÍFICA ≠ VALOR PARA EL BIEN COMÚN**.

## Crecimiento

El catálogo es deliberadamente incompleto. Nuevos hallazgos pueden añadirse después de revisar repositorio, autoría, licencia, función y posibilidad de representación. Los proyectos pueden relacionarse con investigaciones WEB4, Red de Nodos, aprendizaje o Síntesis Abierta™ sin perder nunca el enlace a su fuente.

# EN · English

## What it is

A public, extensible index of open scientific projects found on GitHub that deserve to be **visited, understood and, when rights allow it, visualized or reproduced** from WEB4™.

Selection does not imply that Innova_N, NEOCore™ or the external authors are affiliated. Nor is it a certification of scientific truth. It is an exploration gateway with permanent return to the original source.

## First constellation

### Neuroscience, connectomics and brain

- **malecns · natverse** — R package providing programmatic access to recent Janelia FlyEM datasets; GPL ≥3 licence for the package code.
- **Fly Brain Minecraft** — MaleCNS converted into an LIF network controlling a fly inside Minecraft.
- **DOOMFLY** — MaleCNS experimentation in ViZDoom, including a plasticity line with documented negative results.
- **Fly64** — experimental MaleCNS + Super Mario 64 demonstration; its author warns that it should not be assumed to be reviewed scientific software.
- **Neuroglancer** — WebGL viewer for volumetric neuroscience data.
- **brainrender** — visualization of brain anatomy in atlas space.
- **The Virtual Brain** — whole-brain-scale network simulation.

### Astronomy and the universe

- **Aladin Lite** — lightweight browser sky atlas; basis of the WEB4™ deep-sky viewer prototype.
- **Astropy** — open Python infrastructure for astronomy and astrophysics.
- **OpenSpace** — interactive astrovisualization from planetary to cosmological scales.

### Scientific imaging and visualization

- **napari** — interactive multidimensional viewer for Python.
- **PyVista** — 3D visualization and analysis on top of VTK.

### Biological and molecular simulation

- **OpenWorm** — open initiative aimed at modelling *C. elegans* and moving toward whole-organism simulation.
- **OpenMM** — high-performance molecular-simulation toolkit.

### AI for science

- **AlphaFold** — open-source code for the protein-structure prediction method; its historical repository is archived and retained as a reference rather than an active project.

## How WEB4 visualizes it

The living page does not need to copy screenshots in order to be visual. It can represent every project through a **WEB4-created constellation of nodes**, categories, relationships, licences, activity and states; each node opens its entry and original repository.

External material will only be incorporated inside WEB4 when there is a verified rights basis:

```text
LINK_ONLY
→ our own description + metadata + canonical link

LICENSE_VERIFIED
→ reuse within the exact scope of the licence

EXPLICIT_PERMISSION
→ documented additional permission from the author/rightsholder
```

Repository licence is recorded separately from rights over **data, papers, images, screenshots, logos and trademarks**.

## Minimum inclusion criteria

A project must have an identifiable origin, an understandable scientific or scientific-visualization use and enough information to record provenance. The catalogue preserves repository state, licence when verified and epistemic state. When media rights are missing, the state remains `LINK_ONLY`.

Projects are not ordered by stars. Popularity may be contextual data, but **POPULARITY ≠ SCIENTIFIC VALIDITY ≠ VALUE FOR THE COMMON GOOD**.

## Growth

The catalogue is deliberately incomplete. New discoveries may be added after reviewing repository, authorship, licence, function and representability. Projects may relate to WEB4 research, the Node Network, learning or Open Synthesis™ without ever losing the link to their source.
