# ES · Castellano

## 1. Función

Esta superficie reúne **recursos, datasets, herramientas y experimentos científicos abiertos encontrados en GitHub y fuentes científicas relacionadas** que puedan ser útiles para aprender, explorar, reproducir, contrastar o experimentar.

No es un ranking de popularidad ni una apropiación de trabajo ajeno. Cada ficha debe conservar **autoría, repositorio canónico, licencia, procedencia, estado del proyecto, límites epistemológicos y derechos de visualización/reutilización**.

## 2. Atlas abierto de proyectos científicos

- **[Atlas abierto de proyectos científicos / Open Scientific Projects Atlas](./open-projects/)** — catálogo estructurado y ampliable de proyectos científicos y de visualización científica encontrados en GitHub.
- **[Connectoma completo de Drosophila · MaleCNS](./drosophila-connectome/)** — dataset oficial, exploradores, publicación y experimentos computacionales relacionados, incluyendo Minecraft, DOOMFLY y Fly64, con propuesta NEOCore™ separada del dato biológico.

El catálogo inicial incluye astronomía, neurociencia/connectómica, imagen científica, simulación molecular y biológica, simulación cerebral, visualización 3D e IA aplicada a ciencia. Debe crecer por descubrimiento y verificación, no por copia automática.

## 3. Regla de derechos y visualización

```text
REPOSITORIO PÚBLICO
≠ PERMISO AUTOMÁTICO PARA COPIAR TODO SU CONTENIDO

LICENCIA DE CÓDIGO
≠ LICENCIA AUTOMÁTICA DE SCREENSHOTS / LOGOS / DATOS / PAPERS
```

WEB4™ utiliza tres estados:

- `LINK_ONLY`: mostrar metadatos propios y enlazar al original. No copiar media externa.
- `LICENSE_VERIFIED`: reutilizar o generar visualizaciones sólo dentro del alcance verificado de la licencia aplicable, con atribución cuando corresponda.
- `EXPLICIT_PERMISSION`: el autor o titular ha autorizado expresamente una reutilización adicional concreta.

Cuando no esté claro, **fallar cerrado: enlace, descripción propia y retorno a fuente**.

## 4. Regla epistemológica

Un proyecto enlazado no pasa a formar parte de NEOCore™ por ser citado. WEB4™ debe distinguir:

```text
DATO / DATA
MODELO / MODEL
SCAFFOLDING
RESULTADO OBSERVADO / OBSERVED RESULT
INTERPRETACIÓN / INTERPRETATION
EXPERIMENTO NEOCore™ / NEOCore™ EXPERIMENT
```

Las demos llamativas no se elevan automáticamente a equivalencia biológica, causalidad, conciencia, inteligencia general o validación del marco.

## 5. Fuente de datos para WEB4

Siempre que sea viable, la futura página pública de Ciencia consumirá índices estructurados versionados desde este repositorio. El primer catálogo está en [`open-projects/catalog.json`](./open-projects/catalog.json).

Las visualizaciones de categorías, relaciones, actividad o cobertura deben derivarse de esos metadatos y ser **creación propia de WEB4**, evitando depender de imágenes de terceros cuando no haya permiso claro.

# EN · English

## 1. Purpose

This surface brings together **open scientific resources, datasets, tools and experiments found on GitHub and related scientific sources** that may be useful for learning, exploring, reproducing, challenging or experimenting.

It is neither a popularity ranking nor an appropriation of other people's work. Every entry must preserve **authorship, canonical repository, licence, provenance, project status, epistemic limits and visualization/reuse rights**.

## 2. Open Scientific Projects Atlas

- **[Open Scientific Projects Atlas / Atlas abierto de proyectos científicos](./open-projects/)** — a structured, extensible catalogue of scientific and scientific-visualization projects found on GitHub.
- **[Complete Drosophila connectome · MaleCNS](./drosophila-connectome/)** — official dataset, explorers, publication and related computational experiments, including Minecraft, DOOMFLY and Fly64, with the NEOCore™ proposal kept separate from the biological data.

The initial catalogue covers astronomy, neuroscience/connectomics, scientific imaging, molecular and biological simulation, whole-brain simulation, 3D visualization and AI for science. It must grow through discovery and verification, not automatic copying.

## 3. Rights and visualization rule

```text
PUBLIC REPOSITORY
≠ AUTOMATIC PERMISSION TO COPY ALL ITS CONTENT

CODE LICENCE
≠ AUTOMATIC LICENCE FOR SCREENSHOTS / LOGOS / DATA / PAPERS
```

WEB4™ uses three states:

- `LINK_ONLY`: show our own metadata and link to the original. Do not copy external media.
- `LICENSE_VERIFIED`: reuse or generate visualizations only within the verified scope of the applicable licence, with attribution where required.
- `EXPLICIT_PERMISSION`: the author or rights holder has expressly authorized a specific additional reuse.

When unclear, **fail closed: link, our own description and return to source**.

## 4. Epistemic rule

A linked project does not become part of NEOCore™ merely because it is cited. WEB4™ must distinguish:

```text
DATA / DATO
MODEL / MODELO
SCAFFOLDING
OBSERVED RESULT / RESULTADO OBSERVADO
INTERPRETATION / INTERPRETACIÓN
NEOCore™ EXPERIMENT / EXPERIMENTO NEOCore™
```

Striking demos are not automatically promoted to biological equivalence, causality, consciousness, general intelligence or validation of the framework.

## 5. Data source for WEB4

Whenever practical, the future public Science page will consume versioned structured indexes from this repository. The first catalogue lives at [`open-projects/catalog.json`](./open-projects/catalog.json).

Category, relationship, activity or coverage visualizations should be derived from those metadata and be **WEB4-created visualizations**, avoiding reliance on third-party images whenever permission is unclear.
