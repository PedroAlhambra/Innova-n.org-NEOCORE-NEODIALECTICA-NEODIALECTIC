## Principio canónico / Canonical principle

> **El repositorio es la fuente de verdad. La Wiki enseña a usarlo.**
>
> **The repository is the source of truth. The Wiki teaches how to use it.**

La Wiki no debe convertirse en una copia paralela del repositorio ni exigir sincronización manual de cada manifiesto, auditoría, análisis, obra o cambio de estado.

The Wiki must not become a parallel copy of the repository or require manual synchronisation of every manifesto, audit, analysis, work or status change.

## Función de la Wiki / Purpose of the Wiki

La Wiki debe limitarse a:

1. explicar qué es el ecosistema y cómo orientarse;
2. ofrecer rutas de lectura y uso;
3. remitir a índices canónicos del repositorio;
4. explicar cómo participar en Síntesis Abierta™;
5. distinguir material público, canónico, histórico, provisional y restringido;
6. facilitar el acceso a personas no familiarizadas con GitHub.

The Wiki should be limited to:

1. explaining the ecosystem and how to navigate it;
2. offering reading and usage routes;
3. pointing to canonical repository indexes;
4. explaining how to participate in Open Synthesis™;
5. distinguishing public, canonical, historical, provisional and restricted material;
6. making access easier for people unfamiliar with GitHub.

## Qué no debe duplicar / What it must not duplicate

La Wiki no debe mantener:

* listados completos que ya existen en un README o índice;
* copias completas de manifiestos, auditorías o análisis;
* estados operativos que cambian con frecuencia;
* tablas de ASIN, versiones, incidencias o expedientes;
* genealogías que ya quedan fijadas mediante commits;
* documentos cuya actualización requiera una segunda edición manual.

The Wiki should not maintain:

* complete lists already available in a README or index;
* full copies of manifestos, audits or analyses;
* frequently changing operational states;
* ASIN, version, incident or case tables;
* genealogies already fixed through commits;
* documents whose update would require a second manual edition.

## Regla de mantenimiento / Maintenance rule

```text
CAMBIO CANÓNICO
→ commit en el repositorio
→ actualización del índice correspondiente
→ actualización de la Wiki sólo si cambia la forma de uso o navegación
```

```text
CANONICAL CHANGE
→ repository commit
→ update the relevant index
→ update the Wiki only when usage or navigation changes
```

No es necesario actualizar la Wiki por cada documento nuevo. Basta con que el documento quede correctamente enlazado desde su índice canónico.

The Wiki does not need to be updated for every new document. It is sufficient for the document to be correctly linked from its canonical index.
