# ES · Castellano

Este directorio contiene la fuente estable de navegación de la Wiki pública de Innova_N.

## Principio

> **Repositorio = contenido, genealogía y trazabilidad. Wiki = orientación estable y mapa de acceso.**

La Wiki evita copiar inventarios vivos, estados numéricos, listas de candidatos **y números de versión vigentes** que obliguen a rehacer cada página con cada delta.

La versión actual se resuelve exclusivamente desde [`versiones/README.md`](../versiones/README.md). Si una página necesita informar del estado actual, enlaza allí sin copiar el número.

Las versiones sí permanecen cuando forman parte de procedencia material, compatibilidad, snapshots o historia.
