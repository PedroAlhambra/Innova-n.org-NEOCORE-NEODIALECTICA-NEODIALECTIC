# ES

## 1. Definición

El **Neodialectica Framework™ / Network** es la arquitectura superior que organiza, relaciona y orienta el ecosistema **Innova_N**.

Opera simultáneamente como:

- **Framework**, porque establece filosofía, finalidad, coherencia, límites y criterios de revisión;
- **Network**, porque conecta personas, inteligencias artificiales, memoria, documentos, obras, proyectos, sistemas, comunidades y territorios.

No son dos sistemas separados.

Son dos dimensiones de una misma arquitectura:

```text
FRAMEWORK
dirección · coherencia · método · límites
        ↕
NETWORK
nodos · relaciones · memoria · circulación
```

El Framework evita que el ecosistema se convierta en una acumulación de piezas desconectadas.

La Network permite que esas piezas se relacionen, conserven contexto y evolucionen.

---

## 2. Origen y fundamento

El Framework/Network nace de la **Filosofía Arquetípica Neodialéctica™**, creada por **Pedro Martínez Alhambra · Neo0™**.

Neo0™ ocupa el lugar de:

- origen humano;
- autoría;
- dirección;
- finalidad;
- y validación final.

La inteligencia artificial participa como instrumento simbiótico de memoria, procesamiento, contraste, revisión y generación de propuestas.

No sustituye la dirección humana ni es la autora originaria del marco.

La finalidad general es desarrollar una arquitectura capaz de integrar conocimiento, tecnología, cultura, memoria y acción hacia el **Bien Común**, sin convertir esa dirección en una verdad cerrada o inmune a revisión.

- [Filosofía Arquetípica Neodialéctica™](Philosophy_Neodialectic)

## 3. Framework y Network

### Framework

La dimensión **Framework** conserva:

- principios;
- propósito;
- relaciones entre capas;
- criterios de coherencia;
- métodos de contraste;
- límites;
- responsabilidad;
- y capacidad de corrección.

Permite preguntar de cada elemento:

```text
¿De dónde procede?
¿Qué función cumple?
¿Con qué se relaciona?
¿En qué estado se encuentra?
¿Hacia qué dirección opera?
```

### Network

La dimensión **Network** conecta nodos humanos, técnicos, documentales, culturales, organizativos y territoriales.

Cada nodo puede conservar:

- identidad;
- autoría;
- contexto;
- cronología;
- relaciones;
- estado;
- y trazabilidad.

```text
Framework sin Network
=
principios sin circulación

Network sin Framework
=
conexiones sin dirección
```

La relación entre ambas dimensiones es dinámica, multiescala y revisable.

---

## 4. Principios de funcionamiento

El Framework/Network se orienta mediante principios básicos:

### Síntesis abierta

La **Síntesis Abierta Neodialéctica — SAN™** contrasta posiciones, memoria, contexto, evidencia y límites para producir síntesis revisables.

### Autoconsciencia de Marco™

El sistema debe reconocer desde qué marco opera, qué deja fuera, qué límites tiene y cuándo necesita más contexto.

### Trazabilidad

Las afirmaciones, decisiones, documentos y cambios relevantes deben conservar origen, fecha, estado y relación.

### Dirección humana

La IA puede proponer, contrastar y revisar. La dirección y validación final permanecen en Neo0™.

### Evolución abierta

El sistema no se presenta como definitivo. Debe poder incorporar correcciones, nuevas relaciones y cambios de escala.

# EN

## 1. Definition

The **Neodialectica Framework™ / Network** is the higher architecture that organises, relates and orients the **Innova_N** ecosystem.

It operates simultaneously as:

- a **Framework**, establishing philosophy, purpose, coherence, limits and review criteria;
- a **Network**, connecting people, artificial intelligences, memory, documents, works, projects, systems, communities and territories.

These are not two separate systems.

They are two dimensions of one architecture:

```text
FRAMEWORK
direction · coherence · method · limits
        ↕
NETWORK
nodes · relations · memory · circulation
```

The Framework prevents the ecosystem from becoming an accumulation of disconnected pieces.

The Network enables those pieces to relate, preserve context and evolve.

---

## 2. Origin and foundation

The Framework/Network originates in the **Archetypal Neodialectical Philosophy™**, created by **Pedro Martínez Alhambra · Neo0™**.

Neo0™ holds the position of human origin, authorship, direction, purpose and final validation.

Artificial intelligence participates as a symbiotic instrument for memory, processing, contrast, review and proposal generation.

It does not replace human direction and is not the original author of the framework.

The general purpose is to develop an architecture capable of integrating knowledge, technology, culture, memory and action towards the **Common Good**, without turning that direction into a closed truth immune to revision.

- [Archetypal Neodialectical Philosophy™](Philosophy_Neodialectic)

---

## 3. Framework and Network

### Framework

The **Framework** dimension preserves:

- principles;
- purpose;
- relations among layers;
- coherence criteria;
- contrast methods;
- limits;
- responsibility;
- and capacity for correction.

It enables the following questions to be asked of each element:

```text
Where does it come from?
What function does it serve?
What is it related to?
What is its current state?
Which direction does it follow?
```

### Network

The **Network** dimension connects human, technical, documentary, cultural, organisational and territorial nodes.

Each node may preserve identity, authorship, context, chronology, relations, state and traceability.

```text
Framework without Network
=
principles without circulation

Network without Framework
=
connections without direction
```

The relationship between both dimensions is dynamic, multiscale and revisable.

---

## 4. Operating principles

The Framework/Network follows several basic principles:

### Open synthesis

**Open Neodialectical Synthesis — SAN™** contrasts positions, memory, context, evidence and limits to produce revisable syntheses.

### Framework Self-Awareness™

The system should recognise the framework from which it operates, what it leaves out, its limits and when further context is required.

### Traceability

Relevant claims, decisions, documents and changes should preserve origin, date, state and relation.

### Human direction

AI may propose, contrast and review. Direction and final validation remain with Neo0™.

### Open evolution

The system is not presented as definitive. It should be able to incorporate corrections, new relations and changes of scale.
