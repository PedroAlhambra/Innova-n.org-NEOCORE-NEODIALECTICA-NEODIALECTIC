# ES · Castellano

Este repositorio no utiliza un único canal para todo. Elige la puerta según la naturaleza del asunto:

| Necesidad | Ruta |
|---|---|
| Entender el marco | [`README.md`](./README.md) y [`versiones/README.md`](./versiones/README.md) |
| Aportar crítica, fuente, evidencia, relación o delta | [Síntesis Abierta™](./propuestas/sintesis-abierta/README.md) |
| Saber cómo contribuir | [`CONTRIBUTING.md`](./CONTRIBUTING.md) |
| Proponer un Neoaxioma o contrastar uno | [Neoaxiomas™](./neoaxiomas/README.md) |
| Traer un problema externo o caso auditable | [Auditorías Públicas · Leónidas™](./auditorias/publicas/README.md) |
| Proponer grupo/comunidad/proyecto como nodo WEB4™ | plantilla `grupo_comunidad_web4.yml` al abrir un Issue |
| Proponer un cambio concreto de archivos | Pull Request siguiendo la plantilla del repositorio |
| Reportar vulnerabilidad técnica | [`SECURITY.md`](./SECURITY.md) |
| Problema de conducta | [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md) |
| Consultar uso/reutilización del contenido | [`LICENSE`](./LICENSE) |
| Navegar la experiencia pública | [innova-n.org](https://innova-n.org/) |

Antes de abrir un Issue nuevo, busca si ya existe una Síntesis o auditoría dedicada. Reutilizar el nodo correcto conserva genealogía y evita fragmentación.

```text
DUDA / APORTE
→ BUSCAR NODO EXISTENTE
→ ENTRAR EN SU ISSUE / DOCUMENTO
→ CREAR NUEVO NODO SÓLO SI HAY DELTA REAL
```

Las preguntas de uso general pueden plantearse en Discussions cuando no exista un Issue/Síntesis específico. Las vulnerabilidades explotables, datos personales sensibles y secretos no deben trasladarse a canales públicos.

# EN · English

This repository does not use one channel for every request. Choose the gateway according to the nature of the matter:

| Need | Route |
|---|---|
| Understand the framework | [`README.md`](./README.md) and [`versiones/README.md`](./versiones/README.md) |
| Contribute criticism, sources, evidence, relations or a delta | [Open Synthesis™](./propuestas/sintesis-abierta/README.md) |
| Learn how to contribute | [`CONTRIBUTING.md`](./CONTRIBUTING.md) |
| Propose or scrutinise a Neoaxiom | [Neoaxioms™](./neoaxiomas/README.md) |
| Bring an external problem or auditable case | [Public Audits · Leónidas™](./auditorias/publicas/README.md) |
| Propose a group/community/project as a WEB4™ node | use `grupo_comunidad_web4.yml` when opening an Issue |
| Propose a concrete file change | Pull Request using the repository template |
| Report a technical vulnerability | [`SECURITY.md`](./SECURITY.md) |
| Conduct problem | [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md) |
| Check content use/reuse | [`LICENSE`](./LICENSE) |
| Navigate the public experience | [innova-n.org](https://innova-n.org/) |

Before opening a new Issue, search for an existing dedicated Synthesis or audit. Reusing the correct node preserves genealogy and avoids fragmentation.

```text
QUESTION / CONTRIBUTION
→ SEARCH EXISTING NODE
→ ENTER ITS ISSUE / DOCUMENT
→ CREATE A NEW NODE ONLY WHEN THERE IS A REAL DELTA
```

General-use questions may go to Discussions when no specific Issue/Synthesis exists. Exploitable vulnerabilities, sensitive personal data and secrets must not be moved into public channels.
