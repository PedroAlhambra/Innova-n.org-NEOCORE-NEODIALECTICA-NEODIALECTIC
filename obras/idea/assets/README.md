# ES · Castellano

## Función

Este directorio reúne recursos editoriales y visuales vinculados a **IDEA (1997–2002 · edición pública 2026)** dentro del nodo documental canónico de la obra.

Los archivos de esta carpeta deben conservar su relación con la edición, idioma, formato y finalidad para la que fueron generados. Un recurso visual aislado no sustituye a los documentos canónicos de edición ni a los archivos maestros de publicación.

## Reglas de trazabilidad

- conservar, cuando sea posible, nombre de archivo, fecha y función editorial;
- distinguir portada, contraportada, cubierta completa, recurso promocional y material de prensa;
- no tratar una exportación derivada como archivo maestro si no está identificada como tal;
- mantener la relación con el nodo documental de IDEA y con el índice de ediciones;
- documentar las sustituciones importantes mediante commit en lugar de borrar su genealogía sin explicación.

# EN · English

## Purpose

This directory gathers editorial and visual assets associated with **IDEA (1997–2002 · public 2026 edition)** within the work's canonical documentary node.

Files stored here should preserve their relationship to the edition, language, format and purpose for which they were produced. An isolated visual asset does not replace canonical edition documentation or publication master files.

## Traceability rules

- preserve file name, date and editorial function whenever possible;
- distinguish front cover, back cover, full wrap, promotional asset and press material;
- do not treat a derived export as a master file unless it is explicitly identified as such;
- maintain links to the IDEA documentary node and edition index;
- document material replacements through commits rather than erasing their genealogy without explanation.
