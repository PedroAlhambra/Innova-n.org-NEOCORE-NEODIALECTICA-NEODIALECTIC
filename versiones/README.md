## Política de referencias

Un número de versión sólo debe permanecer fuera de los READMEs principales cuando sea información material y no dinámica, por ejemplo:

- versión en la que nació o fue introducido un mecanismo;
- procedencia de una decisión o cambio;
- snapshot o fijación histórica;
- compatibilidad mínima/máxima explícita;
- transición histórica real, incluida una fase pre-canónica;
- documento específico de una versión.

No debe mantenerse un número simplemente para decir «esta es la versión actual» dentro de manifiestos, propuestas, análisis, Issues, Wiki intermedia o documentación de producto.

```text
CURRENT_VERSION ≠ VERSION_OF_ORIGIN
CURRENT_VERSION ≠ COMPATIBILITY_VERSION
CURRENT_VERSION ≠ HISTORICAL_VERSION
```
