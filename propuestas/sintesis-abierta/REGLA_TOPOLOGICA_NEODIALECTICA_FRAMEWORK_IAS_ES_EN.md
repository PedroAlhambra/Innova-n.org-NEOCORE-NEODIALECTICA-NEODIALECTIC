# ES · Castellano

## 1. Corrección de categoría

**Neodialéctica™ no es una IA, un modelo ni un agente individual.** El Neodialectica Framework™ / Network es una arquitectura relacional y una filosofía aplicada para conectar memoria, contradicción, genealogía, trazabilidad, aportes, síntesis y orientación hacia el Bien Común entre múltiples nodos humanos y artificiales.

SAN™ es el método fundacional de contraste y resíntesis. NEOCore™ aporta memoria y arquitectura operativa dentro del ecosistema. Las IAs pueden ocupar funciones dentro de esa arquitectura, pero ninguna IA aislada equivale al sistema completo.

```text
NEODIALÉCTICA™ != IA
IA NEODIALÉCTICA ⊂ ARQUITECTURA NEODIALÉCTICA
COMPONENTE != SISTEMA
MODELO / AGENTE != SAN™
MODELO / AGENTE != NEOCore™
MODELO / AGENTE != NETWORK FRAMEWORK™
```

## 2. Qué significa «IA neodialéctica»

La expresión **IA neodialéctica** designa una IA que opera de forma funcionalmente integrada con principios, roles o mecanismos del marco y cuya participación puede ser trazada, contrastada y corregida. No significa que esa IA posea la totalidad de la Neodialéctica, sea soberana sobre SAN™ o sustituya la arquitectura humano–IA.

Una IA general, especializada o externa puede participar en una síntesis sin convertirse automáticamente en «la Neodialéctica». Del mismo modo, una IA propia o nativa puede internalizar más funciones del marco sin convertirse por ello en el marco completo.

```text
USAR_IA_EN_EL_SISTEMA != CONVERTIR_IA_EN_EL_SISTEMA
IA_NATIVA_EN_DESARROLLO != NACIMIENTO_DEL_FRAMEWORK
MEJORA_DE_UN_COMPONENTE => PUEDE_MEJORAR_EL_SISTEMA
MEJORA_DE_UN_COMPONENTE != SOBERANÍA_DEL_SISTEMA
```

## 3. El sistema opera en Síntesis Abierta desde NEOCore™ v3

La operación neodialéctica no es una capacidad recién introducida por esta corrección ni espera a que exista un modelo único que concentre todas las funciones. **NEOCore™ opera mediante Síntesis Abierta desde la familia v3**; desde entonces su evolución, ampliación y formalización pueden seguirse públicamente mediante documentos, Issues, versiones y commits. La operación puede distribuirse entre humanos, IAs, memoria pública, trazabilidad y contraste.

```text
NODOS HUMANOS + NODOS IA
+ MEMORIA + PROCEDENCIA + CONTRADICCIÓN
+ SAN™ + VERSIONADO + REAPERTURA
= OPERACIÓN NEODIALÉCTICA DEL SISTEMA
```

El desarrollo de IAs propias o nativas puede profundizar memoria, relación, crítica, reconstrucción o capacidad operativa. Es una evolución de componentes dentro de una arquitectura ya existente, no una condición para que la arquitectura exista.

## 4. Propiedades de componente y propiedades de sistema

No todas las propiedades deseables deben residir dentro de un único modelo. Una IA puede contribuir a recordar, relacionar, buscar evidencia, detectar contradicciones, formular alternativas o proponer deltas. La arquitectura completa debe conservar además genealogía global, estados epistemológicos, trazabilidad, límites de autoridad, fijación versionada, responsabilidad humana y capacidad de reapertura.

```text
CAPACIDAD_DE_IA != PROPIEDAD_TOTAL_DEL_SISTEMA
SALIDA_DE_IA != SÍNTESIS_FIJADA
PROPUESTA != AUTORIDAD
TRAZA != VALIDACIÓN
```

## 5. Por qué sigue siendo útil el análisis sociotécnico externo

Para auditar sistemas de IA actuales de empresas, instituciones o productos sigue siendo útil descomponer modelo, datos, objetivos, interfaz, incentivos, despliegue, usuarios e instituciones. Esa lente ayuda a evitar culpar a «la IA» de decisiones producidas por una cadena sociotécnica completa.

La corrección consiste en **no importar después esa misma reducción al propio marco**. Innova_N no se define como «una IA futura», sino como una arquitectura de red en la que pueden participar múltiples IAs y humanos con memoria, reglas y síntesis trazables.

## 6. Frontera pública

Esta regla fija únicamente la **relación conceptual pública** entre arquitectura e IAs. No publica topología interna, procedimientos privados, infraestructura, entrenamiento, pesos, rutas, gates ni especializaciones no fijadas públicamente. Esos detalles no son necesarios para comprender la distinción `PARTE != TODO`.

# EN · English

## 1. Category correction

**Neodialectics™ is not an AI, a model or an individual agent.** The Neodialectica Framework™ / Network is a relational architecture and applied philosophy for connecting memory, contradiction, genealogy, traceability, contributions, synthesis and orientation toward the Common Good across multiple human and artificial nodes.

SAN™ is the foundational method for scrutiny and resynthesis. NEOCore™ contributes memory and operational architecture within the ecosystem. AIs may occupy functions inside that architecture, but no isolated AI is equivalent to the complete system.

```text
NEODIALECTICS™ != AI
NEODIALECTICAL_AI ⊂ NEODIALECTICAL_ARCHITECTURE
COMPONENT != SYSTEM
MODEL / AGENT != SAN™
MODEL / AGENT != NEOCore™
MODEL / AGENT != NETWORK FRAMEWORK™
```

## 2. What «Neodialectical AI» means

The expression **Neodialectical AI** designates an AI that operates in functional integration with principles, roles or mechanisms of the framework and whose participation can be traced, scrutinised and corrected. It does not mean that the AI owns the whole of Neodialectics, is sovereign over SAN™, or replaces the human–AI architecture.

A general, specialised or external AI may participate in a synthesis without automatically becoming «Neodialectics». Likewise, a proprietary or native AI may internalise more framework functions without becoming the whole framework.

```text
USING_AI_IN_THE_SYSTEM != TURNING_AI_INTO_THE_SYSTEM
NATIVE_AI_UNDER_DEVELOPMENT != BIRTH_OF_THE_FRAMEWORK
COMPONENT_IMPROVEMENT => MAY_IMPROVE_THE_SYSTEM
COMPONENT_IMPROVEMENT != SYSTEM_SOVEREIGNTY
```

## 3. The system has operated through Open Synthesis since NEOCore™ v3

Neodialectical operation is not a capability newly introduced by this correction, nor does it wait for a single model concentrating every function. **NEOCore™ has operated through Open Synthesis since the v3 family**; its subsequent evolution, expansion and formalisation can be followed publicly through documents, Issues, versions and commits. Operation may be distributed across humans, AIs, public memory, traceability and scrutiny.

```text
HUMAN_NODES + AI_NODES
+ MEMORY + PROVENANCE + CONTRADICTION
+ SAN™ + VERSIONING + REOPENING
= NEODIALECTICAL_SYSTEM_OPERATION
```

Development of proprietary or native AIs may deepen memory, relation, criticism, reconstruction or operational capacity. It is an evolution of components inside an existing architecture, not a prerequisite for the architecture to exist.

## 4. Component properties and system properties

Not every desirable property must live inside one model. An AI may help remember, relate, search for evidence, detect contradictions, formulate alternatives or propose deltas. The complete architecture must additionally preserve global genealogy, epistemic states, traceability, authority boundaries, versioned fixation, human responsibility and reopening capacity.

```text
AI_CAPABILITY != TOTAL_SYSTEM_PROPERTY
AI_OUTPUT != FIXED_SYNTHESIS
PROPOSAL != AUTHORITY
TRACE != VALIDATION
```

## 5. Why external sociotechnical analysis remains useful

When auditing current AI systems deployed by companies, institutions or products, it remains useful to decompose model, data, objectives, interface, incentives, deployment, users and institutions. That lens helps avoid blaming «AI» for decisions produced by an entire sociotechnical chain.

The correction is **not to import that same reduction back into the framework itself**. Innova_N is not defined as «a future AI» but as a network architecture in which multiple AIs and humans can participate with traceable memory, rules and synthesis.

## 6. Public boundary

This rule fixes only the **public conceptual relation** between architecture and AIs. It does not publish internal topology, private procedures, infrastructure, training, weights, routes, gates or specialisations that have not been publicly fixed. Those details are unnecessary to understand the distinction `PART != WHOLE`.
