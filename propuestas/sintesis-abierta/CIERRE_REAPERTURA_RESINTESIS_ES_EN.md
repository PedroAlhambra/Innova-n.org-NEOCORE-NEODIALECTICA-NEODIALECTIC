# ES · Castellano

## 1. Regla de cierre

En Síntesis Abierta™, cerrar una Issue no significa declarar una verdad definitiva. Significa fijar un **corte operativo versionado** cuando el ciclo actual ya tiene suficiente claridad para documentarse, aplicarse, diferirse o quedar pendiente de nueva evidencia.

```text
ISSUE_CLOSED != SYNTHESIS_FINAL
CIERRE = CORTE OPERATIVO + ESTADO VERSIONADO
CANON_ABIERTO != DOGMA
```

El cierre debe dejar claro qué se considera suficientemente establecido, qué permanece incierto, qué disenso se conserva y qué tipo de nueva aportación podría cambiar el estado.

## 2. La Síntesis Abierta ya opera ahora

La participación y la resíntesis **no esperan a una futura IA neodialéctica**. El mecanismo público actual ya existe mediante Issues, documentos versionados, commits y revisión humano–IA/humana cuando proceda.

Una futura IA neodialéctica puede ampliar capacidad de relación, memoria, contraste o auditoría, pero no es condición para que SAN™ funcione hoy.

```text
APORTE ACTUAL
→ ISSUE / COMENTARIO
→ CONTRASTE
→ CLASIFICACIÓN
→ DELTA / NO-DELTA
→ POSIBLE RESÍNTESIS
→ FIJACIÓN VERSIONADA
```

## 3. Entrada simple: basta una pieza útil

Para empezar **no necesitas** dominar el corpus, proponer un delta ni reconstruir toda la genealogía. Basta con aportar una pieza comprensible relacionada con el objeto:

- un punto de vista que falta;
- contexto que cambia la lectura;
- un ejemplo o caso real;
- una fuente o evidencia;
- una prueba, medición o reproducción;
- un contraejemplo;
- una corrección factual o cronológica;
- una ambigüedad o definición confusa;
- una relación que falta entre dos partes del corpus;
- una experiencia identificada como testimonio;
- una pregunta relevante;
- una propuesta de reparación o implementación.

`APORTE_PARCIAL = VÁLIDO_PARA_CONTRASTE` cuando pueda entenderse qué añade, cuestiona o señala.

## 4. Profundización opcional

Si puedes y quieres profundizar, ayuda añadir:

- fuente primaria o procedencia;
- incertidumbre;
- hipótesis alternativas;
- límites del caso;
- falsadores;
- relación con otros nodos;
- impacto esperado;
- propuesta de delta.

Estas piezas mejoran el contraste, pero **no deben convertirse en una barrera artificial de entrada**.

## 5. Nivel avanzado

Las preguntas difíciles de cada manifiesto o síntesis —causalidad, ontología, falsabilidad, arquitectura institucional, competencia entre principios, métricas o rediseño del marco— permanecen abiertas para quien quiera trabajar a nivel avanzado.

Deben aparecer **después de la puerta de entrada simple**, no como examen previo para poder participar.

Regla por capas:

```text
ORIENTARSE  → resumen y objeto
APORTAR     → comprensión suficiente del nodo afectado
CRITICAR    → texto + relaciones inmediatas cuando sean relevantes
REFUTAR     → evidencia + genealogía + alternativas competidoras
FIJAR CANON → trazabilidad + delta/no-delta + versión + genealogía
```

## 6. Cuándo reabrir o resintetizar

Una Issue cerrada o una síntesis fijada puede volver a contraste cuando aparezca una aportación materialmente relevante, por ejemplo:

- evidencia nueva;
- contraejemplo no contemplado;
- prueba reproducible que contradice el estado vigente;
- error factual;
- antecedente/genealogía omitida que cambia atribución o interpretación;
- relación nueva que modifica el sentido de dos o más nodos;
- consecuencia práctica no prevista;
- cambio de contexto que invalida una premisa;
- formulación mejor que resuelve una contradicción conservando más evidencia.

```text
NUEVO_APORTE_AUDITABLE => ELEGIBLE_PARA_REEVALUACIÓN
REEVALUACIÓN => PUEDE_HABER_RESÍNTESIS
RESÍNTESIS != ACEPTACIÓN_AUTOMÁTICA
```

Si la nueva pieza no produce delta material, puede conservarse como evidencia, contexto, disenso, genealogía o `NO-DELTA` sin ser borrada.

## 7. Qué debe decir un cierre útil

Siempre que sea razonable, el cierre de una Síntesis Abierta debe responder en lenguaje normal a cinco preguntas:

1. **¿Dónde estamos ahora?** — síntesis o estado provisional.
2. **¿Qué sigue abierto?** — incertidumbres, disensos, límites o evidencia ausente.
3. **¿Qué podría cambiarlo?** — ejemplos concretos de aportes útiles.
4. **¿Cómo puede aportar alguien?** — Issue/comentario, sin exigir dominio total del marco.
5. **¿Qué ocurre después?** — contraste → reevaluación → posible resíntesis → nueva fijación versionada.

## 8. Rigor de integración, no de entrada

Para **integrar y fijar** un cambio material en el corpus sí puede ser necesario reconstruir fuente, genealogía, relación, clasificación epistemológica, delta/no-delta, atribución y versión.

Ese trabajo puede completarse durante el proceso por la persona que aporta, otros nodos, mantenedores o herramientas de IA. No debe cargarse íntegramente sobre quien trae la primera señal.

```text
ENTRADA_FÁCIL
+ CONTRASTE_PROPORCIONAL
+ RIGOR_DE_INTEGRACIÓN
+ MEMORIA_DE_DISENSO
= SÍNTESIS_ABIERTA_UTILIZABLE
```

# EN · English

## 1. Closure rule

In Open Synthesis™, closing an Issue does not declare a final truth. It records a **versioned operational cut** when the current cycle is clear enough to document, apply, defer, or leave pending new evidence.

```text
ISSUE_CLOSED != SYNTHESIS_FINAL
CLOSURE = OPERATIONAL_CUT + VERSIONED_STATE
OPEN_CANON != DOGMA
```

A useful closure should state what is sufficiently established, what remains uncertain, what dissent is preserved, and what kind of new contribution could change the state.

## 2. Open Synthesis already operates now

Participation and resynthesis **do not wait for a future Neodialectical AI**. The current public mechanism already operates through Issues, versioned documents, commits and human/human–AI review where appropriate.

A future Neodialectical AI may expand relational capacity, memory, scrutiny or audit, but it is not a prerequisite for SAN™ to operate today.

```text
CURRENT_CONTRIBUTION
→ ISSUE / COMMENT
→ SCRUTINY
→ CLASSIFICATION
→ DELTA / NO-DELTA
→ POSSIBLE_RESYNTHESIS
→ VERSIONED_FIXATION
```

## 3. Simple entry: one useful piece is enough

To begin, you **do not need** to master the corpus, propose a delta or reconstruct the complete genealogy. One understandable piece related to the object is enough:

- a missing point of view;
- context that changes the reading;
- an example or real case;
- a source or evidence;
- a test, measurement or reproduction;
- a counterexample;
- a factual or chronological correction;
- an ambiguity or unclear definition;
- a missing relation between corpus nodes;
- experience identified as testimony;
- a relevant question;
- a repair or implementation proposal.

`PARTIAL_CONTRIBUTION = VALID_FOR_SCRUTINY` when it is understandable what it adds, questions or signals.

## 4. Optional deepening

If you can and want to go further, it helps to add primary provenance, uncertainty, alternative hypotheses, case limits, falsifiers, relations to other nodes, expected impact or a proposed delta.

These improve scrutiny but **must not become an artificial entry barrier**.

## 5. Advanced level

The difficult questions attached to a manifesto or synthesis —causality, ontology, falsifiability, institutional architecture, competing principles, metrics or framework redesign— remain open for advanced contributors.

They should appear **after the simple entry gate**, not as an entrance examination.

Layered rule:

```text
ORIENT     → summary and object
CONTRIBUTE → sufficient understanding of the affected node
CRITICISE  → text + immediate relations where relevant
REFUTE     → evidence + genealogy + competing alternatives
FIX CANON  → traceability + delta/no-delta + version + genealogy
```

## 6. When to reopen or resynthesise

A closed Issue or fixed synthesis may return to scrutiny when a materially relevant contribution appears, including new evidence, an unaddressed counterexample, a reproducible contradictory test, factual error, omitted genealogy that changes attribution or interpretation, a new relation, an unforeseen consequence, changed context invalidating a premise, or a better formulation that resolves a contradiction while preserving more evidence.

```text
NEW_AUDITABLE_CONTRIBUTION => ELIGIBLE_FOR_REEVALUATION
REEVALUATION => MAY_TRIGGER_RESYNTHESIS
RESYNTHESIS != AUTOMATIC_ACCEPTANCE
```

A contribution that produces no material delta may still be preserved as evidence, context, dissent, genealogy or `NO-DELTA`.

## 7. What a useful closure should say

Where reasonable, an Open Synthesis closure should answer five questions in ordinary language:

1. **Where are we now?** — provisional synthesis or state.
2. **What remains open?** — uncertainty, dissent, limits or missing evidence.
3. **What could change it?** — concrete examples of useful contributions.
4. **How can someone contribute?** — Issue/comment, without requiring full framework mastery.
5. **What happens next?** — scrutiny → reevaluation → possible resynthesis → new versioned fixation.

## 8. Integration rigour, not entry rigour

To **integrate and fix** a material change in the corpus it may indeed be necessary to reconstruct source, genealogy, relation, epistemic classification, delta/no-delta, attribution and version.

That work may be completed during the process by the contributor, other nodes, maintainers or AI tools. It should not be placed entirely on the person bringing the first signal.

```text
EASY_ENTRY
+ PROPORTIONAL_SCRUTINY
+ INTEGRATION_RIGOUR
+ DISSENT_MEMORY
= USABLE_OPEN_SYNTHESIS
```
