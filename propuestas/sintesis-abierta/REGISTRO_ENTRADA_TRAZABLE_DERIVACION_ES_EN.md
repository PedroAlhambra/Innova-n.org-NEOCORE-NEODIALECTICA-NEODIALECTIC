# ES · Castellano

## Para qué sirve

Este registro permite que una persona, IA, institución, equipo o proyecto **declare públicamente que entra en relación con el marco** sin necesidad de adherirse a él.

Puede utilizarse para:

- registrar lectura o seguimiento voluntario;
- indicar que se recibió un enlace o contacto de Innova_N;
- anunciar una investigación, crítica o contraste;
- declarar una implementación, adaptación o derivación;
- conservar genealogía y atribución;
- pedir orientación hacia el Issue correcto de Síntesis Abierta;
- mantener una vía estable de seguimiento aunque el corpus evolucione.

## Lo que NO significa

Registrar entrada no significa:

- adhesión ideológica;
- aceptación del marco;
- licencia automática;
- incorporación al canon;
- cesión de derechos;
- representación de Innova_N;
- validación de una hipótesis o derivación.

## Abrir registro

**[Registrar entrada / derivación →](https://github.com/PedroAlhambra/Innova-n.org-NEOCORE-NEODIALECTICA-NEODIALECTIC/issues/new?template=registro_entrada_derivacion.yml)**

El propio usuario de GitHub actúa como identificador público mínimo. No publiques credenciales, documentos confidenciales ni datos personales innecesarios.

## Flujo

```text
LECTURA / CONTACTO
→ REGISTRO DE ENTRADA
→ OBJETO Y FINALIDAD DECLARADOS
→ ORIENTACIÓN AL NODO CORRECTO
→ APORTE / DERIVACIÓN SI EXISTE
→ CONTRASTE
→ DELTA
→ COMMIT
```

## Privacidad

La mera lectura pública no genera un registro nominal obligatorio. Este mecanismo registra **actos voluntarios de entrada reconocible, aporte o derivación**.

Si una aportación llega por correo, se aplica además el [Puente de Participación Guiada · Correo ↔ GitHub](./PUENTE_PARTICIPACION_GUIADA_CORREO_GITHUB_ES_EN.md): ningún contenido privado se publica sin autorización explícita.

## Genealogía de derivaciones

Cuando exista una obra, implementación o sistema derivado, se recomienda conservar:

```text
FUENTE
+ FECHA / SHA
+ PERSONA / EQUIPO / PROYECTO
+ OBJETO DERIVADO
+ ENLACE PÚBLICO
+ DIFERENCIAS / DELTA
+ RETORNO A FUENTE
```

La futura política jurídica de licencias determinará qué obligaciones de atribución son exigibles además de esta regla metodológica.

# EN · English

## Purpose

This register lets a person, AI, institution, team or project **publicly declare entry into a relationship with the framework** without having to endorse it.

It may be used to register voluntary reading/follow-up, note that an Innova_N link or outreach message was received, announce research or criticism, declare an implementation or derivative, preserve genealogy and attribution, request routing to the correct Open Synthesis Issue, and maintain a stable follow-up route as the corpus evolves.

## What it does NOT mean

Entry registration does not mean ideological adhesion, acceptance, automatic licensing, canonical incorporation, transfer of rights, representation of Innova_N, or validation of a hypothesis or derivative.

## Open the register

**[Register entry / derivation →](https://github.com/PedroAlhambra/Innova-n.org-NEOCORE-NEODIALECTICA-NEODIALECTIC/issues/new?template=registro_entrada_derivacion.yml)**

Your GitHub account acts as the minimum public identifier. Do not publish credentials, confidential documents or unnecessary personal data.

## Flow

```text
READING / CONTACT
→ ENTRY REGISTER
→ DECLARED OBJECT AND PURPOSE
→ ROUTING TO THE RIGHT NODE
→ CONTRIBUTION / DERIVATION IF ANY
→ CONTRAST
→ DELTA
→ COMMIT
```

## Privacy

Public reading alone does not create a mandatory named record. This mechanism records **voluntary acts of recognisable entry, contribution or derivation**.

Email contributions are additionally governed by the [Guided Participation Bridge · Email ↔ GitHub](./PUENTE_PARTICIPACION_GUIADA_CORREO_GITHUB_ES_EN.md): private material is not published without explicit permission.

## Derivative genealogy

Where a derivative work, implementation or system exists, preserve source, date/SHA, person/team/project, derived object, public link, differences/delta and return-to-source path.

Future licensing policy will determine which attribution duties are legally enforceable in addition to this methodological rule.
