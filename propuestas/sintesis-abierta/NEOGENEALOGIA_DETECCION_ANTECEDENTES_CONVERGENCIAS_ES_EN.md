# ES · Castellano

## 1. Por qué se abre

El marco necesita una forma explícita de mirar **hacia atrás, hacia los lados y contra sí mismo**.

Cada vez que aparece una idea histórica, científica, filosófica, institucional o técnica que se parece a una pieza de la Neodialéctica™, la respuesta correcta no es apropiársela ni defender automáticamente una prioridad total. La respuesta correcta es reconstruir su genealogía y preguntar qué demuestra realmente.

**NeoGenealogía™** se abre para convertir esa operación en método.

Su función no es proteger el ego del marco. Es aumentar su precisión.

```text
ENCONTRAR UN ANTECEDENTE
≠ PERDER EL MARCO

ENCONTRAR UN ANTECEDENTE
= MEJORAR LA GENEALOGÍA
+ CALIBRAR LA NOVEDAD
+ DESCUBRIR CONTRAEJEMPLOS
+ ENTENDER RECURRENCIAS
```

## 2. Qué significa «proto-neodialéctico»

La etiqueta **PROTO-ND** designa una **afinidad estructural parcial verificable anterior a la formulación pública de la Neodialéctica**.

No significa que el autor histórico fuera neodialéctico, que utilizara este vocabulario, que conociera el marco futuro o que su obra pertenezca retrospectivamente a Innova_N.

Es una clasificación actual sobre una relación documental actual.

```text
PROTO-NEODIALÉCTICO
= AFINIDAD PARCIAL ANTERIOR

PROTO-NEODIALÉCTICO
≠ AUTOR NEODIALÉCTICO RETROACTIVO
≠ DERIVACIÓN
≠ APROPIACIÓN DE AUTORÍA
```

## 3. Reglas de integridad genealógica

```text
ANTECEDENTE ≠ DERIVACIÓN
CONVERGENCIA ≠ COPIA
PRECEDENCIA ≠ COMPLETITUD
SIMILITUD ≠ EQUIVALENCIA
CORRELACIÓN TEMPORAL ≠ INFLUENCIA DEMOSTRADA
NOVEDAD DE UNA PARTE ≠ NOVEDAD DEL SISTEMA
NOVEDAD DEL SISTEMA ≠ NOVEDAD DE CADA PARTE
```

Toda afirmación de influencia, apropiación o derivación exige una cadena documental adicional. La mera similitud no basta.

## 4. Clases iniciales

### PROTO-ND · Antecedente proto-neodialéctico

Patrón anterior a la formulación pública de la Neodialéctica con afinidad funcional verificable respecto de una parte del marco.

### CONV-ND · Convergencia independiente

Patrón similar desarrollado de forma independiente cuando no existe evidencia suficiente de derivación entre los nodos comparados.

### DER-ND · Derivación demostrable

Relación para la que sí existe trazabilidad suficiente de acceso, lectura, cita, adaptación, implementación o transmisión.

### CTR-ND · Contraejemplo genealógico

Caso histórico o contemporáneo que tensiona, limita o refuta una formulación del marco. Tiene el mismo derecho de entrada que una convergencia favorable.

### FALSO-PAR · Semejanza insuficiente

Coincidencia verbal, estética o superficial que no conserva función, alcance, teleología o arquitectura suficiente para declarar convergencia material.

## 5. Matriz de Contraste Genealógico™

Cada caso debería intentar conservar, cuando exista información suficiente:

| Campo | Pregunta |
|---|---|
| Fuente primaria | ¿Dónde puede comprobarse? |
| Fecha | ¿Cuándo aparece de forma trazable? |
| Actor / autoría | ¿Quién lo formuló, ejecutó o documentó? |
| Dominio | ¿Biología, IA, filosofía, política, ingeniería, cultura...? |
| Problema detectado | ¿Qué tensión intenta resolver? |
| Mecanismo | ¿Qué hizo realmente? |
| Teleología | ¿Para qué finalidad explícita? |
| Participación | ¿Quién pudo intervenir y quién quedó fuera? |
| Reversibilidad | ¿Podía detenerse, revisarse o revertirse? |
| Trazabilidad | ¿Se conservaron razones, decisiones y cambios? |
| Resultado | ¿Qué ocurrió después? |
| Relación ND | PROTO-ND / CONV-ND / DER-ND / CTR-ND / FALSO-PAR |
| Efecto sobre el marco | confirma parcialmente / limita / obliga a matizar / refuta / abre nuevo delta |

No se propone un «porcentaje de neodialéctica». Una puntuación única escondería precisamente las diferencias que interesa conservar.

## 6. Test de novedad relacional

NeoGenealogía™ obliga a descomponer cualquier afirmación de novedad.

Ante una coincidencia debe preguntarse si el elemento actual es:

```text
RENOMBRADO
RECOMBINACIÓN
EXTENSIÓN
GENERALIZACIÓN
IMPLEMENTACIÓN NUEVA
ARQUITECTURA RELACIONAL NUEVA
O IDEA YA EXISTENTE SIN DELTA MATERIAL SUFICIENTE
```

El valor de una arquitectura puede residir en una relación nueva entre componentes conocidos. Por ello, demostrar antecedentes de algunas piezas no demuestra por sí solo que el conjunto sea anterior ni posterior.

A la inversa, la novedad del conjunto tampoco permite atribuir como nuevas todas sus piezas.

## 7. Flujo operativo

```text
SEÑAL / CASO
→ RETORNO A FUENTE
→ CRONOLOGÍA
→ DESCOMPOSICIÓN FUNCIONAL
→ MATRIZ DE CONTRASTE GENEALÓGICO™
→ BÚSQUEDA DE CONTRAEJEMPLOS
→ CLASIFICACIÓN PROVISIONAL
→ EFECTO SOBRE AFIRMACIONES DE NOVEDAD
→ DELTA
→ SAN™
→ COMMIT / TRAZA
→ REVISIÓN SI APARECE NUEVA EVIDENCIA
```

## 8. Relación con Umbral-X™

Umbral-X™ no se utiliza aquí para excluir antecedentes incómodos. Se utiliza para exigir señal suficiente antes de afirmar una relación material.

Una coincidencia débil puede quedar como pista. Una coincidencia fuerte debe volver a las fuentes. Una contradicción fuerte debe entrar en síntesis aunque reduzca una afirmación de originalidad del propio marco.

## 9. Primer caso: Asilomar

El primer caso registrado es **PROTO-ND-001 · Asilomar 1974–1975**, ampliado con la recurrencia **Asilomar AI 2017**.

El patrón histórico verificable incluye:

```text
CAPACIDAD TÉCNICA NUEVA
+ INCERTIDUMBRE SOBRE RIESGO
→ APLAZAMIENTO VOLUNTARIO DE CIERTOS EXPERIMENTOS
→ DELIBERACIÓN
→ CONDICIONES DE CONTINUIDAD
→ GUÍAS / SUPERVISIÓN POSTERIOR
```

El caso no prueba la Neodialéctica ni convierte a sus protagonistas en precursores del marco completo. Sí documenta que la **autolimitación informada, la pausa ante incertidumbre y la deliberación previa al escalado** tienen antecedentes históricos claros.

## 10. Pausa Competente™ · hipótesis operativa abierta

Asilomar hace visible una formulación útil que se abre a contraste, **sin elevarla todavía a Neoaxioma**:

> **Potencia técnica ≠ permiso automático de despliegue.**

Cuando la capacidad de intervenir crece más deprisa que la capacidad disponible para **comprender, atribuir, contener o reparar** sus consecuencias, puede existir un deber proporcional de **Pausa Competente™** antes de escalar.

La competencia técnica da especial capacidad para detectar la señal y responsabilidad para advertir. **No concede por sí sola soberanía sobre las consecuencias colectivas.**

Por ello el flujo propuesto es:

```text
SEÑAL COMPETENTE
→ UMBRAL DE RIESGO
→ PAUSA PROPORCIONAL Y REVISABLE
→ CONTRASTE TÉCNICO + AFECTADOS + EVIDENCIA + GOBERNANZA
→ DECISIÓN TRAZABLE
→ REANUDAR / MODIFICAR / LIMITAR / DETENER
→ REVISAR
```

Una pausa no es necesariamente prohibición. Puede ser una operación de control de calidad civilizatoria.

## 11. Efecto epistemológico

NeoGenealogía™ cambia la forma en que el marco debe responder a los antecedentes.

```text
«ESO YA EXISTÍA»
NO SE RESPONDE CON DEFENSA AUTOMÁTICA

SE RESPONDE CON:
¿QUÉ EXISTÍA?
¿DESDE CUÁNDO?
¿CON QUÉ ALCANCE?
¿CON QUÉ RESULTADOS?
¿QUÉ FALTA?
¿QUÉ SOBRA EN NUESTRA FORMULACIÓN?
¿QUÉ DEBEMOS CORREGIR?
```

Un antecedente bien encontrado es un aporte a SAN™.

## 12. Marco vivo, no snapshot obligatorio

La apertura de NeoGenealogía™ **avanza el organismo vivo del marco sin exigir un snapshot por cada delta**.

El commit conserva el cambio; el Issue conserva la contradicción; las fuentes conservan la genealogía. Los snapshots pueden utilizarse cuando exista una necesidad técnica o documental específica, pero no sustituyen la evolución continua de la rama canónica.

# EN · English

## 1. Why this mechanism is opened

The framework needs an explicit way to look **backwards, sideways and against itself**.

Whenever a historical, scientific, philosophical, institutional or technical idea resembles one component of Neodialectics™, the correct response is neither retrospective appropriation nor automatic defence of total priority. The correct response is to reconstruct genealogy and ask what the evidence actually establishes.

**NeoGenealogy™** turns that operation into a method.

Its function is not to protect the framework's ego. Its function is to increase precision.

```text
FINDING AN ANTECEDENT
≠ LOSING THE FRAMEWORK

FINDING AN ANTECEDENT
= IMPROVING GENEALOGY
+ CALIBRATING NOVELTY
+ DISCOVERING COUNTEREXAMPLES
+ UNDERSTANDING RECURRENCES
```

## 2. Meaning of «proto-neodialectical»

**PROTO-ND** denotes a **verifiable partial structural affinity that predates the public formulation of Neodialectics**.

It does not mean that the historical actor was Neodialectical, used this vocabulary, knew the future framework, or belongs retrospectively to Innova_N.

## 3. Genealogical integrity rules

```text
ANTECEDENT ≠ DERIVATION
CONVERGENCE ≠ COPYING
PRECEDENCE ≠ COMPLETENESS
SIMILARITY ≠ EQUIVALENCE
TEMPORAL CORRELATION ≠ DEMONSTRATED INFLUENCE
NOVELTY OF A PART ≠ NOVELTY OF THE SYSTEM
NOVELTY OF THE SYSTEM ≠ NOVELTY OF EVERY PART
```

Claims of influence, appropriation or derivation require additional documentary chains.

## 4. Initial classes

- **PROTO-ND** · proto-neodialectical antecedent.
- **CONV-ND** · independent convergence.
- **DER-ND** · demonstrable derivation or influence.
- **CTR-ND** · genealogical counterexample.
- **FALSE-PAIR** · insufficient or merely superficial similarity.

## 5. Genealogical Contrast Matrix™

Each case should preserve, where evidence permits: primary source, date, authorship, domain, detected problem, mechanism, teleology, participation, reversibility, traceability, outcome, ND relation and effect on the framework.

No single «percentage of Neodialectics» is proposed. A scalar score would hide the differences that the mechanism exists to preserve.

## 6. Relational novelty test

For each apparent match, ask whether the current element is a renaming, recombination, extension, generalisation, new implementation, new relational architecture, or an already-existing idea without sufficient material delta.

Prior art for individual components does not automatically settle the novelty of a larger architecture. Conversely, novelty of an architecture does not make all its components novel.

## 7. Operational flow

```text
SIGNAL / CASE
→ RETURN TO SOURCE
→ CHRONOLOGY
→ FUNCTIONAL DECOMPOSITION
→ GENEALOGICAL CONTRAST MATRIX™
→ SEARCH FOR COUNTEREXAMPLES
→ PROVISIONAL CLASSIFICATION
→ EFFECT ON NOVELTY CLAIMS
→ DELTA
→ OPEN SYNTHESIS™
→ COMMIT / TRACE
→ REVISION WHEN NEW EVIDENCE APPEARS
```

## 8. Relation to Umbral-X™

Umbral-X™ does not exclude uncomfortable antecedents. It requires sufficient signal before a material relation is asserted. Strong contradictions enter synthesis even when they reduce the framework's own originality claims.

## 9. First case: Asilomar

The first registered case is **PROTO-ND-001 · Asilomar 1974–1975**, extended with the recurrence **Asilomar AI 2017**.

It documents historical precedents for informed self-limitation, pausing under uncertainty and deliberation before scaling. It does not turn the participants into authors of the later framework.

## 10. Competent Pause™ · open operational hypothesis

Asilomar makes visible a useful proposition, opened for scrutiny **without yet elevating it to a Neoaxiom**:

> **Technical capability ≠ automatic licence to deploy.**

When intervention capability grows faster than the available ability to understand, attribute, contain or repair consequences, there may be a proportional duty of **Competent Pause™** before scaling.

Technical competence gives particular capacity to detect the signal and responsibility to warn. **It does not by itself grant sovereignty over collective consequences.**

## 11. Epistemic effect

A well-established antecedent is an input to Open Synthesis, not an attack that must be resisted. NeoGenealogy™ asks what existed, when, at what scope, with what outcomes, and what the current framework must correct.

## 12. Living framework, not mandatory snapshot

Opening NeoGenealogy™ advances the living framework without requiring a snapshot for every delta. Commits preserve change; Issues preserve contradiction; sources preserve genealogy. Snapshots remain optional tools for specific technical or documentary needs, not substitutes for continuous canonical evolution.
